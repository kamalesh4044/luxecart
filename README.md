# 💎 LuxeCart: Premium E-Commerce Experience

**LuxeCart** is a high-end, immersive e-commerce platform built with **Next.js 15** and **Three.js**. It focuses on minimalist aesthetics, smooth micro-animations, and a professional-grade user experience.

---

## 🚀 Experience Highlights

- **✨ Ultra-Minimalist UI**: Clean, airy design inspired by luxury brands like Apple and Tesla.
- **🪄 Framer Motion Animations**: Sophisticated, staggered entrance animations and smooth transitions.
- **🧊 Glassmorphism**: Floating, blurred-background navigation and UI elements.
- **📦 Bento-Grid Layout**: Modern product showcase optimized for high-conversion retail.
- **⚡ Next.js 15 Power**: Leveraging the latest React features and App Router architecture.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Graphics**: Three.js / React Three Fiber (for 3D Product Previews)

---

## 📐 Components Built

- **`Navbar.tsx`**: A floating glass navigation bar with entrance animations.
- **`Hero.tsx`**: A high-impact landing section with sophisticated typography.
- **`Global Design System`**: Custom tokens for a consistent luxury feel.

---

## 🏃 Getting Started

### Prerequisites
- Node.js (v20+)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/luxecart.git
   cd luxecart
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
